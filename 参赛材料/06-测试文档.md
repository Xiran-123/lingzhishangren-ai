## 二、测试报告

### 测试环境
- 服务器：公网云服务器，Docker 容器部署
- 客户端：Chrome 浏览器最新版
- 大模型：Kimi-K2.6 via SiliconFlow API

### 测试结果汇总

| 模块 | 用例数 | 通过 | 失败 | 通过率 |
|------|-------|------|------|--------|
| 登录与认证 | 5 | 5 | 0 | 100% |
| AI 智能问答 | 5 | 5 | 0 | 100% |
| 沉浸式剧情 | 3 | 3 | 0 | 100% |
| 练习与错题 | 4 | 4 | 0 | 100% |
| 能力分析报告 | 5 | 5 | 0 | 100% |
| 教师驾驶舱 | 3 | 3 | 0 | 100% |
| 知识库与课件 | 3 | 3 | 0 | 100% |
| 桌宠 | 3 | 3 | 0 | 100% |
| **合计** | **31** | **31** | **0** | **100%** |

### 已知限制
1. 大模型 API 响应速度受网络影响，复杂问题可能需要 5-15 秒
2. PPT 转换依赖 LibreOffice，超大文件转换耗时较长
3. 能力分析基于关键词匹配 + AI 综合，数据量少时分析结果较为笼统

## 三、数据集说明

本作品不使用外部公开数据集，所用数据均为系统运行生成：

| 数据类型 | 来源 | 说明 |
|---------|------|------|
| 学生档案 | 测试账号注册生成 | 虚拟姓名、学号、班级，不涉及真实个人 |
| 对话记录 | 测试过程中与 AI 对话生成 | 内容为通信工程学习相关 |
| 练习题 | 大模型基于知识点动态生成 | 不涉及真实考试题目 |
| 知识库 PPT | 测试上传的教学课件 | 为公开教学内容或自制 |
| 能力数据 | 系统根据互动自动计算 | 基于12维能力模型 |
