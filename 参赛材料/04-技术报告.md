# 04-技术报告

## 一、系统概述

灵智尚人是一款面向通信工程专业的 AI 智能教学平台，采用 B/S 架构，以 Flask 为后端框架，结合大语言模型 API，实现智能问答、沉浸式教学、个性化能力分析等核心功能。平台支持学生与教师双角色，通过数据驱动实现因材施教。

---

## 二、技术栈

| 层次 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | HTML5 + CSS3 + JavaScript | 原生前端，Chart.js 图表渲染，无重型框架 |
| 后端 | Python 3 + Flask | 轻量 Web 框架，RESTful 接口 |
| 大模型 | Moonshot Kimi-K2.6（通过 SiliconFlow API 调用） | 负责智能问答、剧情生成、能力分析 |

| 文档处理 | LibreOffice | PPT 转图片预览 |
| 容器化 | Docker + Gunicorn | 云端部署，多线程 Worker |
| 云服务器 | 腾讯云 / 公网服务器 | IP: 150.158.149.95，端口 5000 |

## 四、核心功能模块实现

### 4.1 智能问答引擎
- **流式响应**：采用 Server-Sent Events (SSE) 实现 AI 回复逐字输出
- **关键技术点**：
  - HTTP 头设置 `X-Accel-Buffering: no`、`Cache-Control: no-cache, no-transform` 禁用代理缓冲
  - Docker 环境设置 `PYTHONUNBUFFERED=1` 禁用 Python 输出缓冲
  - Gunicorn 配置 `--no-sendfile`，`threads=8`，`timeout=180s`
- **能力维度识别**：对学生提问进行关键词匹配，命中 12 维能力关键词时累计对应维度得分

### 4.2 沉浸式剧情演练
- 预置通信工程场景剧本（5G 基站、核心网、传输网等）
- 支持 AI 动态生成自定义剧情场景
- 对话推进式交互，记录学生决策并评估工程能力

### 4.3 练习与错题引擎
- 按知识点调用大模型生成练习题
- 提交答案后自动判分与解析
- 错题自动收录，支持「已掌握」标记
- 基于错题的复习推荐算法

### 4.4 能力分析引擎
- **12 维能力模型**：通信原理、信号与系统、移动通信、光纤通信、交换技术、IP 网络、网络安全、工程伦理、工程实践、团队协作、创新思维、自主学习
- **聚合为 5 大类**：理论基础、专业核心、工程实践、工程伦理、综合素质
- **AI 个性化分析**：综合学生最近 30 条对话 + 12 维能力数据 + 错题本 + 学习记录，组装结构化 prompt 调用大模型，输出【优势】【不足】【学习建议】【整体评价】

### 4.5 教师智能驾驶舱
- 班级学情聚合：学生数、平均能力分、任务完成率、风险预警
- 班级下钻：查看班级内学生明细
- **班级整体 AI 分析**：汇总全班 12 维平均掌握度、活跃度分布、学生摘要，AI 生成【学情概述】【共性问题】【教学建议】【重点关注学生】【后续教学重点】
- 练习题管理、知识库上传、班级通知

### 4.6 PPT 课件管理
- 教师上传 PPT，后端通过 LibreOffice 转换为图片用于在线预览
- 学生端可浏览、预览、下载教师上传的课件
- 支持状态标识：✅ 可预览 / ⚙️ 转换中 / 源文件已删除

## 五、数据结构

### 学生档案（students.json）
```json
{
  "student_id": "学号",
  "name": "姓名",
  "class_name": "班级",
  "total_questions": 提问次数,
  "competence_analysis": {
    "communication_theory": 得分,
    ...（12 维）
  },
  "wrong_questions": [...],
  "learning_records": [...]
}
```

### 对话记录
- 按会话（conversation）组织，每条消息含 role、content、timestamp
- 教师端可查看学生对话并审核优质问答入库

## 七、部署方案

### 本地运行
```bash
pip install -r requirements.txt
python app.py
# 访问 http://localhost:5000
```

### Docker 部署
```bash
docker build -t lingzhishangren .
docker run -d -p 5000:5000 \
  -v /data:/app/data \
  -v /uploads:/app/uploads \
  -e SECRET_KEY=固定密钥 \
  lingzhishangren
```

### 一键部署脚本
- `deploy.ps1`：Windows 端打包并通过 SCP 上传至服务器，远程重建容器
- 排除数据文件（/data、/uploads），避免部署覆盖学生数据

## 九、创新点

1. **AI 个性化能力分析**：不仅统计得分，更综合对话内容、错题、学习行为，由大模型生成深度分析与个性化学习建议
2. **沉浸式剧情教学**：将通信工程知识融入岗位模拟剧情，提升学习代入感
3. **双角色协同**：教师驾驶舱 + 学生学习端，实现数据驱动的精准教学
4. **桌宠陪伴式交互**：AI 回复等待时桌宠主动陪聊，降低等待焦虑
5. **12 维能力模型**：覆盖理论、实践、伦理、素质全方位能力评估
