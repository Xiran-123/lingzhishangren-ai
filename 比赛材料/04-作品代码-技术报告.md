## 1. 作品概述

### 1.1 背景与目标

通信工程类课程实践性强，但传统实训教学存在三大痛点：

1. **实训资源受限**：真实基站勘察、机房施工等场景难以进课堂；
2. **个性化辅导缺失**：一个教师难以应对几十名学生的差异化答疑与错题辅导；
3. **能力评价主观**：工程能力（排障、勘察、设计）难以量化评价。

本作品以大语言模型为核心引擎，构建"**AI 双师 + 虚拟仿真实训 + 数据驱动评价**"一体的工程训练平台，让 AI 承担助教答疑、场景生成、排障辅导、学情分析四类角色。

### 1.2 核心亮点（创新之处）

| 创新点 | 说明 |
|---|---|
| **AI 自动生成场景实训** | 输入任意工程主题，LLM 按结构化 JSON 规范（6 种步骤类型）自动生成 7 步交互式实训流程（含评分规则），实现实训内容"无限扩展" |
| **口语化排障** | 学生用自然语言描述故障现象，AI 结合故障注入上下文辅助定位根因，替代传统"菜单式"排障 |
| **数据驱动的胜任力画像** | 基于答题、排障、实训行为数据，自动生成技术/沟通/项目管理/安全伦理/创新思维 5 维雷达图与学习路径 |
| **全链路错题闭环** | 答错自动入错题本 → 桌宠定期提醒 → 掌握标记 → 复习推荐 |
| **星辰 Agent 双形态** | 同一后端既提供 Web 完整应用，又暴露标准化 API（X_API_Key 鉴权）供星辰 Agent 以插件方式接入，实现"平台内智能体 + 自部署系统"双形态交付 |
| **AI 合规设计** | 全部 AI 生成内容带「✨ AI 生成内容」显式标识；学习行为记录与 AI 闲聊隔离，防止污染学情数据 |

## 3. 关键技术实现

### 3.1 AI 调用层

- 统一封装 `chat/completions` 调用（`API_URL`、`MODEL_NAME` 配置于 app.py 顶部）；
- 聊天采用 **SSE 流式输出**，前端逐帧渲染；
- 场景生成使用**结构化输出约束**：Prompt 中严格定义 6 种步骤类型（text/choice/quiz/siteselect/survey/design）的 JSON Schema，配合解析容错，保证生成结果可直接驱动实训引擎。

### 3.2 配置说明（复现必读）

| 配置项 | 位置 | 说明 |
|---|---|---|
| 大模型 API Key | 环境变量 `SILICONFLOW_API_KEY`，或源码/`exe 同级目录`下的 `api_key.local` 文件（一行纯文本） | 出于安全考虑，密钥不写入源码（`api_key.local` 已加入 .gitignore，不随代码提交）；读取优先级：环境变量 > 本地密钥文件 |
| 模型名 | app.py `MODEL_NAME` | Pro/moonshotai/Kimi-K2.6，可替换为任意兼容 OpenAI 接口的模型 |
| 学生访问密码 | app.py `ACCESS_PASSWORD` | 【请填写实际密码】 |
| 服务端口 | app.py 末尾 `app.run(port=5000)` | 如占用可修改 |

> 源码运行前请二选一配置密钥：
> ```bash
> # 方式一：环境变量
> set SILICONFLOW_API_KEY=sk-xxxxxxxx   # Windows
> export SILICONFLOW_API_KEY=sk-xxxxxxxx # Linux/Mac
> ```
> 或在源码目录新建 `api_key.local` 文件，内容为一行密钥。

### 3.3 数据文件清单（运行时自动生成/读写）

`students.json`（学生档案/任务/测验）、`conversations.json`（会话）、`wrong_questions.json`（错题本）、`classes.json`（班级）、`notifications.json`（通知）、`job_recruitments.json`（岗位）、`search_logs.json`（检索日志）、`upload_history.json`（上传历史）、`wrong_questions_agent.json` 等。

### 3.4 合规性技术设计

1. **AI 内容标识**：AI 回复气泡、AI 题库卡片、AI 生成实训（生成面板声明 + 页面常驻角标）三处显式「✨ AI 生成内容」标识；
2. **数据隔离**：桌宠闲聊请求（persona='pet'）跳过学习画像更新与日志落库，避免非学习行为污染学情数据；
3. **隐私**：全部演示数据为合成测试数据（测试员/2026000000001 等），不含任何真实个人信息。

## 4. 功能模块与路由总览

### 4.1 页面路由（Web UI）

| 路由 | 页面 |
|---|---|
| `/` | 登录 + 聊天主页面（含会话侧边栏、桌宠） |
| `/exercise-page` | 互动练习（题库/错题闭环） |
| `/wrong-questions-page` | 错题本 |
| `/scenario-page` / `/scenario-demo` | 沉浸式场景实训（含 AI 场景生成 ✨） |
| `/weekly-tasks-page` | 每周任务卡（故障注入/排障/测验/报告） |
| `/knowledge-graph-page` | 知识图谱 |
| `/student-portrait-page` / `/student-report-page` | 学生画像/报告（教师） |
| `/job-recruitment-page` | 岗位招聘匹配 |
| `/upload-knowledge-page` | 上传知识库（PPT/Word 解析） |
| `/search-logs-page` / `/class-notification-page` / `/survey-page` | 检索日志 / 班级通知 / 问卷 |

### 4.2 业务 API（节选）

- 聊天：`POST /chat`（SSE 流式）；会话管理：`/api/conversations`（GET/POST/改名/删除/消息）
- 练习：`/api/exercises/generate`、`/api/exercises/submit`（答错自动入错题本）；教师题库：`/api/teacher/exercises/*`（增/删/批量加/**JSON 导入**/**模板下载**）
- 实训：`/scenarios`、`/start-scenario`、`/scenario-progress`、`/api/scenario/generate`（AI 生成）
- 任务：`/api/weekly-tasks/<id>/{detail,quiz,troubleshoot,report,evaluation,lock-status,unlock}`
- 画像：`/api/competence-radar`、`/api/learning-curve`、`/api/knowledge-graph`
- 岗位：`/api/jobs`（统计/收藏/投递/导出）、`/api/job-scheduler/*`（定时抓取）

### 4.3 星辰 Agent 公开 API（api_public.py，X_API_Key 鉴权）

`/api/v1/health`、`/api/v1/knowledge-points`、`/api/v1/exercises/generate|submit`、`/api/v1/wrong-questions(/{id}/master)`、`/api/v1/ask`、`/api/v1/knowledge-detail`、`/api/v1/learning-curve`、`/api/v1/competence-radar`、`/api/v1/job-match`、`/api/v1/knowledge-graph`、`/api/v1/review/recommend`、`/api/v1/scenarios(/{id}|/chat)`、`/api/v1/learning-records` 等，可直接配置为星辰 Agent「API 插件」。

## 5. 复现步骤（确保可复现）

### 5.1 环境要求
- Windows 10/11（exe 路线）或任意可运行 Python 3.9+ 的系统（源码路线）
- 可访问 SiliconFlow 推理服务的网络

### 5.2 exe 路线（最快）
1. 解压作品压缩包 → 双击 `灵智尚人_AI助手.exe`；
2. 浏览器访问 `http://localhost:5000`，按《Demo 体验文档》登录体验。

### 5.3 源码路线
```bash
pip install -r requirements.txt
# 配置 API Key（见 3.2 节），然后：
python app.py
# 访问 http://localhost:5000
```

> exe 重新打包命令：`pyinstaller 灵智尚人_AI助手.spec --noconfirm`
