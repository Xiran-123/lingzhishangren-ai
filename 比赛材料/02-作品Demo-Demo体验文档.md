## 一、作品简介

灵智尚人是一个面向高校通信/电子类专业的 **AI 工程训练平台**，以科大讯飞星辰 Agent 生态理念构建"AI 双师课堂"：

- **学生侧**：AI 智能问答、沉浸式场景实训、互动练习与错题本、每周任务卡（动态故障注入 + 口语化排障）、胜任力画像、岗位招聘匹配；
- **教师侧**：班级管理、题库管理（含 JSON 批量导入）、学生分析、AI 助教配置、教学驾驶舱；
- **AI 能力**：基于大语言模型（Kimi-K2.6，SiliconFlow 推理服务）实现智能问答、实训场景自动生成、口语化排障辅助、学习行为分析。

系统内所有 AI 生成内容均已添加「✨ AI 生成内容」显式标识，符合伦理与安全合规承诺第 c 条。

## 二、体验方式一：一键启动（推荐，Windows）

### 2.1 解压与启动

1. 解压压缩包到任意目录（建议路径不含特殊字符）；
2. 双击 `灵智尚人_AI助手.exe`，等待控制台显示 `Running on http://127.0.0.1:5000`；
3. 浏览器访问 **http://localhost:5000**。

> 首次运行如被 Windows SmartScreen 拦截：点击「更多信息」→「仍要运行」。
> 无需安装 Python 及任何依赖，数据文件自动生成在 exe 同级目录。

## 四、核心功能体验指引

### 4.1 AI 智能问答（主页面）
登录后进入对话主页面，可直接向 AI 提问通信工程问题（如"5G NR 子载波间隔有哪些？"），支持：
- 流式输出回复；每条 AI 回复顶部带「✨ AI 生成内容」标识；
- 上传图片提问；追问、一键复制；
- 左侧边栏（豆包风格）：历史会话切换、重命名、删除、新建会话。

### 4.2 沉浸式场景实训（本次重点升级）
- 入口：主页面 →「🎬 剧情演绎」/ 场景演绎页面；
- 默认场景「基站勘察设计虚拟仿真实训」：7 步全交互流程（项目背景 → 岗位选择 → 站点摸测 → 参数查询 → 基站选址 → 勘察表测量 → 基站设计），含 12 分制评分、星级评定；
- 顶栏可切换「剧情演绎模式 / 自由探索模式」；
- **AI 自动生成实训**：点击页面右下角 ✨ 按钮，输入任意主题（如"光纤铺设工程勘察"），AI 自动生成同规格的完整交互式实训；生成后右下角显示「✨ 本实训场景由 AI 生成」。

### 4.3 互动练习与错题本
- 入口：主页面 →「✏️ 互动练习」；
- 选择知识点生成练习题；答错自动进入错题本，答题反馈即时显示「📕 已自动记录到错题本」；
- 入口：主页面 →「📕 错题本」查看/标记掌握；
- 桌宠会不定期主动提醒剩余错题数。

### 4.4 每周任务卡（动态故障注入 + 口语化排障）
- 入口：主页面 →「📋 每周任务」；
- 打开任务卡 → 学习 PPT/知识库 → 前置安全自检 → 描述故障现象（口语化，AI 辅助定位根因）→ 完成问答题测验（60 分及格，连续 3 次不及格触发失败锁定）→ 自动生成工程报告与闭环评价。

## 五、星辰 Agent 对接说明（可选体验）

系统同步暴露了一套**公网 API 接口**（`api_public.py`，Flask 5000 端口），已按星辰 Agent 插件规范配置，可通过星辰 Agent 平台以"API 插件"方式接入智能体：

- 鉴权方式：请求头 `X_API_Key`（下划线命名）；
- 代表性接口：
  - `GET /api/v1/health` 健康检查
  - `GET /api/v1/knowledge-points` 知识点列表
  - `POST /api/v1/exercises/generate` 生成练习（参数：knowledge_point, count）
  - `POST /api/v1/exercises/submit` 提交答案（参数：question_id, student_answer）
  - `GET /api/v1/wrong-questions` 错题本
  - `POST /api/v1/ask` AI 问答
  - `GET /api/v1/learning-curve` / `competence-radar` / `knowledge-graph` / `job-match` / `review/recommend` 等

完整接口清单与出入参见《技术报告》第 5 节。

## 六、常见问题

| 问题 | 处理 |
|---|---|
| 双击 exe 无反应 | 等待 10~20 秒（首次解压资源）；检查 5000 端口是否被占用 |
| 页面打不开 | 确认控制台显示 Running on http://127.0.0.1:5000；关闭代理后刷新 |
| AI 无回复 | 需联网；检查网络（大模型经 SiliconFlow 推理服务调用） |
| 数据在哪里 | exe 同级目录下自动生成的 JSON 文件（students.json 等） |
